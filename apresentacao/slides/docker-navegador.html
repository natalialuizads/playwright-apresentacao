Só o navegador, em Linux, igual ao do CI

// playwright.config.ts

use: {

  connectOptions: {

    wsEndpoint: process.env.PW_NAVEGADOR_REMOTO,

    exposeNetwork: '<loopback>', // o container vê o seu localhost

  },

}

docker compose -f docker-compose.e2e.yml \

  --profile navegador up -d navegador

PW_NAVEGADOR_REMOTO=ws://127.0.0.1:3000/ \

  npm run e2e:visual

Para quê: screenshots da regressão visual iguais aos do CI no macOS e no Windows, sem rodar a suíte inteira no container.

O segundo jeito: a suíte continua na sua máquina, só o navegador roda no container, com o comando playwright run-server. O config conecta por WebSocket com connectOptions, e o exposeNetwork com loopback deixa o navegador do container acessar o localhost da sua máquina, onde estão o ng serve e o BFF. Para que serve: a regressão visual compara pixels, e fonte de macOS ou Windows é diferente da de Linux. Com o navegador no container, o screenshot que você gera localmente é igual ao do CI. Conferimos o fluxo com run-server e PW_NAVEGADOR_REMOTO.
