Page Object: a tela vira uma classe

e2e/pages/login.page.ts

import { Page } from '@playwright/test';

 

export class LoginPage {

  constructor(private page: Page) {}

 

  async entrar(cpf: string, senha: string) {

    const p = this.page;

    await p.goto('/login');

    await p.getByLabel('CPF').fill(cpf);

    await p.getByLabel('Senha').fill(senha);

    await p.getByRole('button', { name: 'Entrar' })

      .click();

  }

}

e2e/saldo.spec.ts

test('vê o saldo', async ({ page }) => {

  const login = new LoginPage(page);

  await login.entrar('12345678909', 's3nha');

  await expect(page.getByTestId('saldo'))

    .toBeVisible();

});

A tela mudou? Você ajusta um arquivo, não quarenta testes.

Page Object é o mesmo princípio de um service no Angular: esconder o como e expor o quê. O teste fala a língua do negócio, login.entrar, e o detalhe de qual campo preencher fica num lugar só. Para fluxos maiores, dá para ter um Page Object por tela ou por componente compartilhado, como o cabeçalho.
