Quatro dicas para o nosso tipo de front

Material tem papéis

mat-select é um combobox e cada mat-option é um option.

getByRole('combobox', { name: 'Conta' })

Fuja do que o Angular gera

_ngcontent-*, ng-star-inserted e ids automáticos mudam a cada build.

getByTestId('btn-transferir')

Web Components e MFEs

Locators atravessam Shadow DOM aberto, sem configuração extra.

getByLabel('Valor') // dentro do componente

Remote fora do ar

Bloqueie o remoteEntry e confira se o shell mostra o fallback.

page.route('**/remoteEntry.js', r => r.abort())

Dicas específicas do nosso contexto. Componentes do Angular Material já vêm com papéis ARIA, então o getByRole funciona direto. O que o Angular gera em tempo de build nunca deve virar seletor. Para Web Components e microfrontends, os locators do Playwright, exceto XPath, enxergam dentro de Shadow DOM aberto. E com Module Federation dá para simular um remote indisponível e validar o fallback do shell, um cenário que quase ninguém testa.
