Quatro dicas para o nosso tipo de front

Material tem papéis

mat-select é um combobox e cada mat-option é um option.

getByRole('combobox', { name: 'Conta' })

Fuja do que o Angular gera

_ngcontent-*, ng-star-inserted e ids automáticos mudam a cada build.

getByTestId('btn-transferir')

Web Components e MFEs

Locators atravessam Shadow DOM aberto, sem configuração extra.

getByLabel('Valor') // dentro do componente

Rotas com lazy loading

Espere pela URL ou pelo título da tela, nunca pelo chunk carregar.

await expect(page).toHaveURL(/\/extrato$/)

Dicas específicas do nosso contexto. Componentes do Angular Material já vêm com papéis ARIA, então o getByRole funciona direto. O que o Angular gera em tempo de build nunca deve virar seletor. Para Web Components e microfrontends, os locators do Playwright, exceto XPath, enxergam dentro de Shadow DOM aberto. E nas rotas com lazy loading, o teste espera pelo que o usuário vê, a URL ou o título, e não pelo carregamento do chunk. Microfrontends ganham um slide só deles logo a seguir.
