Dia a dia · hábitos

Boas práticas, em código

Papel primeiro

page.getByRole('button',

  { name: 'Pagar' })

Resiste a mudanças de CSS e ainda cobra acessibilidade.

Dados pela API

await request.post(

  '/api/contas', { data });

Criar pela API é muito mais rápido do que pela tela.

Passos com nome

await test.step('paga',

  async () => { ... });

O relatório e o trace mostram cada etapa.

Etiquetas

test('Pix',

  { tag: '@smoke' },

  async ({ page }) => {...});

Rode só o essencial: --grep @smoke.

Retry com trace

retries: 2,

trace: 'on-first-retry',

A falha chega com o raio-x, sem rodar tudo gravando.

Mock nas bordas

page.route('**/api/cotacao',

  r => r.fulfill({ json }));

Serviço de terceiro fora do teste, o seu back de verdade dentro.

O espelho do slide anterior: cada hábito com o trecho de código que o resume. Papel primeiro, dados criados pela API, passos nomeados com test.step, etiquetas para rodar só o essencial, retries com trace e mocks só nas bordas do sistema. Todos esses trechos estão no projeto tatu-web e rodam na suíte.
