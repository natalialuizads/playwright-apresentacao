Pipeline · relatórios

Faça o teste contar a história no relatório

test('Pix de R$ 25 gera comprovante', {

  tag: '@pix',

  annotation: { type: 'issue',

    description: 'https://jira.tatu.test/browse/PIX-142' },

}, async ({ page }, testInfo) => {

  await test.step('abrir a tela do Pix', async () => {

    await page.goto('/pix');

  });

  await test.step('enviar R$ 25 para a Mãe', async () => {

    // ...

  });

  await testInfo.attach('resposta do BFF', {

    body: JSON.stringify(corpo, null, 2),

    contentType: 'application/json',

  });

});

Quatro recursos transformam o relatório de uma lista de nomes em algo que outra pessoa consegue ler. A tag vira filtro clicável. A annotation coloca no topo do teste o link do chamado ou a regra de negócio, e o link é clicável. O test.step troca o log de cliques por passos com nomes de negócio, com o tempo de cada um. E o testInfo.attach anexa a evidência que você quiser: o JSON da resposta do BFF, uma imagem do comprovante, um log. Em ambiente regulado isso vira evidência de teste para auditoria.
