O que não fazer

Dormir no teste

await page

  .waitForTimeout(3000);

Lento quando sobra, quebra quando falta.

Olhar uma vez só

const ok = await

  el.isVisible();

expect(ok).toBe(true);

Não espera nada. Use expect(el).toBeVisible().

Seletor de layout

locator('.col-md-6 > div a')

Quebra no próximo redesign. Prefira papel ou testid.

Forçar o clique

await btn.click(

  { force: true });

Esconde bug real: botão coberto ou desabilitado.

Testes encadeados

test('cria a conta', ...);

test('usa a conta', ...);

Um falha e dez falham. E não roda em paralelo.

Esquecer o .only

test.only('meu teste',

  async () => { ... });

No CI só ele roda. Barre com forbidOnly: true.

Seis erros que aparecem em quase toda suíte que dá dor de cabeça. Os três primeiros causam testes instáveis: esperar por tempo, olhar o estado uma vez só e depender de seletor de layout. O force true silencia a checagem de ação do Playwright e deixa o bug passar. Teste que depende de outro impede o paralelismo. E o test.only esquecido faz o CI rodar um único teste e ficar verde, o pior tipo de falso positivo.
