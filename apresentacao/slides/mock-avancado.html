Editar a resposta e conferir o pedido

Troca só o saldo, o resto é real

await page.route('**/api/conta', async (r) => {

  const res = await r.fetch();

  const conta = await res.json();

  await r.fulfill({

    response: res,

    json: { ...conta, saldo: 0 },

  });

});

Confere o que o front enviou

const req = page.waitForRequest('**/api/pix');

await enviarPix('mae@tatu.com.br', 150);

 

expect((await req).postDataJSON()).toEqual({

  chave: 'mae@tatu.com.br',

  valor: 150,

});

Ótimo para saldo zerado, nome gigante ou campo nulo.

Comece a esperar antes do clique, não depois.

Dois truques que resolvem muita coisa. À esquerda: route.fetch busca a resposta real e você muda só um campo, então o teste não fica preso a um JSON inteiro que pode desatualizar. À direita: o teste confere o corpo que o Angular mandou para a API. É assim que a gente pega bug de contrato, como valor indo como texto em vez de número. A espera começa antes do clique para não perder a requisição.
