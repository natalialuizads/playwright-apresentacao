Roteiro

Quatro paradas, do conceito ao pipeline

01

Conceitos

Browser, context e page; locators, assertions, auto-wait e a comparação com o Cypress.

02

Frontend Angular

Setup, primeiro teste, mocks, Page Objects, Shadow DOM e microfrontends.

03

Backend Java

JUnit 5, testes de API, de tela, mocks com WireMock e integração com Spring Boot.

04

Dia a dia

Um desafio, boas práticas, relatórios, acessibilidade, CI e o que fazer na segunda-feira.

Quatro blocos. Os conceitos valem para as duas linguagens: a API é a mesma, muda só a sintaxe. Por isso quem é de backend não deve pular a parte de Angular, e vice-versa.
