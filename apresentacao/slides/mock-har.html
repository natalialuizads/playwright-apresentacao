Mock · organização

Gravar respostas reais e mockar sem repetição

HAR: grava uma vez, reproduz sempre

await page.routeFromHAR('e2e/hars/extrato.har', {

  url: '**/api/extrato',

  update: !!process.env.HAR_UPDATE,

});

 

# grava com o BFF real no ar

HAR_UPDATE=1 npx playwright test

O arquivo vai para o Git. Depois, o teste roda sem o BFF.

Fixture: atalhos de mock

export const test = base.extend({

  bff: async ({ page }, use) =>

    use(new Bff(page)),

});

 

test('vazio', async ({ bff, extrato }) => {

  await bff.json('**/api/extrato', []);

  await extrato.abrir();

  await expect(extrato.vazio).toBeVisible();

});

Duas formas de não espalhar JSON pelo código. O HAR é uma gravação da rede: você roda uma vez com o BFF real e o Playwright salva as respostas num arquivo; nas próximas execuções ele responde a partir do arquivo. A fixture bff é uma classe pequena que esconde o page.route: o teste fica dizendo o quê, não o como. As duas estão no projeto de exemplo, em 04-har.spec.ts e fixtures.ts.
