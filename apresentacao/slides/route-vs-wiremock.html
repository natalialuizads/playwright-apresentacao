Não competem: o Playwright não vê a chamada que o BFF faz para o serviço de terceiro. A tela usa page.route; o BFF usa WireMock.

Os dois mockam HTTP, mas em pontos diferentes do fio. O page.route intercepta dentro do navegador: só vale para o que a página chama, vive durante um teste e é perfeito para colocar a tela em qualquer estado. O WireMock é um servidor HTTP de mentira: o seu backend aponta para ele no lugar do serviço de terceiro, então serve para qualquer cliente, em qualquer linguagem, e pode ficar de pé para uma suíte inteira. Os dois gravam e repetem respostas: no Playwright com HAR, no WireMock com recording. Para fluxos com estado, como a primeira chamada falhar e a segunda passar, o WireMock tem scenarios; no Playwright você conta as chamadas no handler. Na prática você usa os dois: page.route nos testes do Angular e WireMock nos testes do Spring Boot, como no CotacaoWireMockIT.
