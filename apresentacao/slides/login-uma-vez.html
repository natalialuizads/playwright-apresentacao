Angular · autenticação

Faça login uma vez, reaproveite em todos

// e2e/auth.setup.ts

import { test as setup } from '@playwright/test';

setup('autentica', async ({ page }) => {

  await new LoginPage(page).entrar(CPF, SENHA);

  await page.context()

    .storageState({ path: '.auth/cliente.json' });

});

 

// playwright.config.ts

projects: [

  { name: 'setup', testMatch: /auth\.setup\.ts/ },

  { name: 'app', dependencies: ['setup'],

    use: { storageState: '.auth/cliente.json' } },

],

Os outros testes já nascem logados.

Atenção: coloque .auth/ no .gitignore. São credenciais de teste.

Logar pela tela em todo teste é o jeito mais rápido de ter uma suíte lenta. O projeto setup roda primeiro, faz o login de verdade e grava o estado do navegador. Os demais projetos dependem dele e já começam com a sessão carregada. Com MFA e limite de tentativas de login, isso é ainda mais importante.
