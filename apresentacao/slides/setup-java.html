Uma dependência no pom e pronto

pom.xml

<dependency>

  <groupId>com.microsoft.playwright</groupId>

  <artifactId>playwright</artifactId>

  <version>1.59.0</version>

  <scope>test</scope>

</dependency>

terminal ou CI

# baixa os navegadores antes dos testes

mvn exec:java -e \

  -D exec.mainClass=com.microsoft.playwright.CLI \

  -D exec.args="install --with-deps"

Mesmos conceitos: Playwright, Browser, BrowserContext, Page e Locator.

Síncrono: nada de async e await.

@UsePlaywright integra ao JUnit 5 e injeta as fixtures.

Na sua máquina, a primeira execução baixa os navegadores sozinha.

Confira a versão mais recente no Maven Central antes de fixar.

Uma dependência só, com escopo de teste. O pacote traz o driver e os navegadores são baixados na primeira execução. No CI vale rodar o install antes, com --with-deps, para instalar também as bibliotecas do sistema. A integração com JUnit via @UsePlaywright surgiu na versão 1.42 e a documentação ainda a marca como experimental. Antes de apresentar, confirme no Maven Central qual é a versão mais recente.
