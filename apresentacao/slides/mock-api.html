Angular · mock do BFF

page.route: a tela em qualquer estado

test('avisa quando o BFF falha', async ({ page }) => {

  await page.route('**/api/extrato', route =>

    route.fulfill({ status: 500 }));

 

  await page.goto('/extrato');

 

  await expect(page.getByRole('alert'))

    .toContainText('Não foi possível');

});

Estados que você força em uma linha

Lista vazia

route.fulfill({ json: [] })

Erro no servidor

route.fulfill({ status: 500 })

Rede lenta

setTimeout(() => route.continue(), 3000)

Resposta real, um campo trocado

const res = await route.fetch();

Esse é o superpoder do Playwright para o front. Testar o estado de erro, de lista vazia ou de lentidão contra um ambiente real é quase impossível: você teria que derrubar o BFF. Com page.route a requisição é interceptada no navegador e você devolve o que quiser. Regra: mock nas bordas. Use para estados difíceis de reproduzir, não para tudo.
