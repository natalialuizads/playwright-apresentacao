APIRequestContext: Playwright sem navegador

@UsePlaywright(ContasApiTest.Opcoes.class)

class ContasApiTest {

  public static class Opcoes implements OptionsFactory {

    @Override

    public Options getOptions() {

      return new Options().setApiRequestOptions(

        new APIRequest.NewContextOptions()

          .setBaseURL("http://localhost:8080"));

    }

  }

  @Test

  void listaContas(APIRequestContext request) {

    APIResponse resp = request.get("/api/contas?cliente=42");

    assertThat(resp).isOK();

    assertTrue(resp.text().contains("saldo"));

  }

}

Só HTTP. Rápido como um teste de integração.

OptionsFactory define baseURL e headers, como o token, uma vez.

E um POST?

request.post("/api/pix",

  RequestOptions.create()

    .setData(Map.of("valor", 150)));

Aqui o Playwright vira um cliente HTTP com asserções prontas. O APIRequestContext chega como parâmetro do teste, do mesmo jeito que a page chegava no TypeScript. A OptionsFactory configura tudo uma vez: base URL, headers, certificado. O isOK confere status de 200 a 299. E o mesmo request também serve para preparar dados antes de um teste de tela, por exemplo criar uma conta pela API e só depois abrir o navegador.
