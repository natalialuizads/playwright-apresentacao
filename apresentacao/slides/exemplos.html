Mão na massa

Projetos de exemplo: o Banco Tatu

tatu-web

Angular + Playwright. Login, mocks, HAR e Shadow DOM.

npm install

npx playwright install chromium

npm run e2e

# com interface visual

npm run e2e:ui

tatu-api

Spring Boot + Playwright Java. API, tela e WireMock.

mvn test    # unitários

mvn verify  # API, tela e mocks

 

# vendo o navegador

mvn verify -Dheaded=true

Juntos: suba o tatu-api na porta 8080 e o tatu-web passa a usar o back real no lugar do mock em Node.

Os dois projetos seguem a mesma história do banco fictício: login, saldo, extrato, Pix e cotação do dólar. O front sobe sozinho um BFF de mentira em Node, então roda sem Java. O back sobe uma página mínima própria para os testes de tela, então roda sem Angular. Cada pasta tem um README com o passo a passo e a lista do que cada teste ensina.
