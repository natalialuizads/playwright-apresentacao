Ao vivo · prints e gravação

Prints e vídeos feitos pelo próprio teste

// prints

await page.screenshot({ fullPage: true });

await tabela.screenshot();

await page.screenshot({ mask: [saldo] });

 

// vídeo de um trecho, com legenda

await page.screencast.start({ path: 'pix.webm' });

await page.screencast.showActions();

await page.screencast.showChapter('Pix');

 

// no config: grava sozinho quando falha

screenshot: 'only-on-failure',

video: 'retain-on-failure',

Prints: page.screenshot com fullPage pega a página inteira; locator.screenshot pega só um pedaço; mask cobre dado sensível, como saldo e CPF, antes de o print ir para o relatório. Gravação: no config, video retain-on-failure grava todos os testes e guarda só o vídeo dos que falharam, junto com o screenshot e o trace. E as versões recentes trouxeram o page.screencast: o próprio teste grava um trecho, com showActions anotando cada clique e showChapter colocando um título sobre a tela. Este clipe foi gravado assim, pelo teste, sem ferramenta de captura. Serve para demo, para manual e para mostrar um fluxo a quem não roda teste.
