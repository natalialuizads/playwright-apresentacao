As quatro respostas de um route

ChamadaO que fazUse para
route.fulfill()Você respondeLista, vazio, erro 500, erro 422
route.abort()Derruba a conexãoRede caiu, servidor inalcançável
route.continue()Segue para o servidorAtrasar, trocar header ou URL
route.fetch()Busca a real e te entregaMudar um campo da resposta real

Regra de ouro: registre o route antes do goto. Senão a chamada sai antes de o mock existir.

Todo mock de rede no Playwright é um desses quatro. fulfill é o mais comum: você devolve status, JSON e headers. abort simula falha de rede, diferente de um 500, porque o navegador nem recebe resposta. continue deixa passar, opcionalmente com atraso ou com outro header. fetch é o mais esperto: busca a resposta de verdade e deixa você editar antes de entregar à tela. No projeto de exemplo, o arquivo 02-mock-basico.spec.ts tem um teste para cada um.
