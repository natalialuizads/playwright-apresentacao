Angular · setup

Do zero ao ng e2e em um comando

1 · Instale

ng add playwright-ng-schematics

Instala o Playwright Test e liga o ng e2e.

2 · Rode

ng e2e --ui

O webServer sobe o ng serve antes dos testes.

Sem o schematic

npm init playwright@latest

playwright.config.ts

import { defineConfig } from '@playwright/test';

export default defineConfig({

  testDir: './e2e',

  retries: process.env.CI ? 2 : 0,

  use: {

    baseURL: 'http://localhost:4200',

    trace: 'on-first-retry',

  },

  webServer: {

    command: 'npm start',

    url: 'http://localhost:4200',

    reuseExistingServer: !process.env.CI,

  },

});

O schematic da comunidade é o caminho mais curto num projeto Angular 18 ou mais novo: ele integra com o ng e2e. Os três campos que mais importam na configuração: baseURL, para escrever page.goto('/login') sem repetir o host; trace on-first-retry, para ganhar o raio-x quando algo falhar no CI; e webServer, que sobe a aplicação sozinho e reaproveita a que já estiver rodando na sua máquina.
